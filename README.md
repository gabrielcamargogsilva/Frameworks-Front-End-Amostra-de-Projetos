# 📝 Atividade Prática — Projetos Multi-Frameworks

## 🎯 Desafio
Desenvolver, em grupo, quatro projetos Web abordando o mesmo tema, utilizando diferentes tecnologias front-end. Cada projeto deve apresentar uma página funcional, responsiva e organizada, aplicando componentes e os recursos básicos da ferramenta escolhida.

- **Projeto 02:** Aplicação desenvolvida em **Vue.js**
- **Projeto 03:** Aplicação desenvolvida em **Angular**

### 🔹 Atividade 02 — API Express de Data/Hora & Aplicação Front-End em React

**Descrição:**
Desenvolvimento e publicação de uma API REST utilizando Express com uma rota para consulta de data e hora atual, realizando o deploy no Render. Separação da aplicação Front-End desenvolvida em React em um repositório independente para consumir os dados da API criada e renderizá-los em tela.

**Tecnologias:**
- **Back-End:** Node.js / Express / Render
- **Front-End:** React / JavaScript

### 🔹 Atividade 02 — API RESTful CRUD Express, Consumo Front-End e Documentação no Postman

**Descrição:**
Desenvolvimento de um servidor Back-End em Express.js provendo rotas RESTful para realização do ciclo CRUD (Create, Read, Update, Delete) utilizando persistência de dados em arquivo JSON, com deploy publicado no Render. Criação da aplicação Front-End em React para consumo das rotas da API e documentação completa da coleção de endpoints no Postman.

**Tecnologias:**
- **Back-End:** Node.js / Express.js / CORS / Render
- **Front-End:** React / JavaScript / Vercel
- **Ferramentas:** Postman

**🔗 Links da Atividade:**
